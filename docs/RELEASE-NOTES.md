Gray 独立 Windows 桌宠的首次 GitHub Release。版本为 **v1.1.0**，与程序 **1.1.0.0** 和 MSI **1.1.0** 对应。

### 下载

- `Gray-Desktop-Pet-1.1.0-Setup.msi`：真正的 Windows 安装包，按当前用户安装，带开始菜单入口与标准卸载；无需管理员、不设开机自启。
- `Gray-Desktop-Pet-1.1.0-portable.zip`：可选便携版，解压整个目录后运行 `GrayPet.exe`。
- `SHA256SUMS.txt`：以上两个资产的 SHA256。

需要 Windows 10/11 和已安装的 .NET Framework 4.8 或更新版本。安装包不自动安装运行时，且未进行代码签名。

### 功能

透明置顶、拖动、待机/左右走动、九组动作、十六方向视线、单击挥手/双击跳跃、菜单与托盘控制、暂停恢复、屏幕工作区限制和单实例。修复拖动期间布局/DPI 回调提前限界的问题，保留原 Gray 图像。

启动：开始菜单打开 Gray Desktop Pet，或便携目录双击 EXE。退出：右键人物或托盘图标选择“退出”。卸载安装版前先退出 Gray，再通过 Windows“已安装的应用”卸载。

### 验证与限制

- 本次应用程序级测试通过 1,525 项断言。
- 最终 MSI 在非提升的进程中完成安装、已安装程序启动、修复与卸载，退出码全部为 0，测试后无残留进程。
- 仅一块 96 DPI 显示器；实体鼠标操作、透明像素命中、真实多屏/混合 DPI、实时缩放和显示器拔插尚未实测。
- 安装/卸载通过 Windows Installer 命令行验证；安装器 GUI、Settings GUI 和升级场景未作实际 UI 测试。
- 当前没有指定开源许可证。素材包未附独立图像许可；不声明已核实原创或第三方角色权利，见仓库 `NOTICE.md`。

更完整的证据见 `docs/TESTING.md` 和 `docs/INSTALLER-TESTS.md`。
